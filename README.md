# Niwas — Luxury Hotel Booking Platform

A high-end, full-stack web application built to provide a seamless hotel booking experience. Designed with a modern, luxury-focused aesthetic and powered by a robust backend.

## Tech Stack
* **Backend:** Python (Flask)
* **Database:** SQLite
* **Frontend:** HTML5, CSS3 (Custom Animations), JavaScript
* **Authentication:** Flask Sessions

## Key Features
* **Dynamic UI:** Sleek "Black & Amber" color palette with smooth scroll-reveal animations and 3D hover effects.
* **Authentication:** Secure user registration and login system with session persistence.
* **Booking System:** Dynamic room reservation workflow with total price calculation.
* **Admin Dashboard:** Centralized panel for administrators to view and manage guest bookings.
* **Profile Management:** Personalized user dashboard to track reservation status.
